## 🛠️ Cara Menjalankan Proyek (Installation)

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/Donnyspw/Midnight-Castle.git
   ```
2. **Buka melalui Unity Hub:**
   * Klik **Add** -> **Add project from disk**.
   * Pilih folder `Midnight-Castle` yang baru saja di-*clone*.
   * Pastikan versi **Unity Editor** sesuai dengan yang tertera di `ProjectSettings/ProjectVersion.txt`.
3. **Jalankan Game:**
   * Buka *scene* utama di folder `Assets/Scenes`.
   * Tekan tombol **Play** (`Ctrl + P`) di editor.
