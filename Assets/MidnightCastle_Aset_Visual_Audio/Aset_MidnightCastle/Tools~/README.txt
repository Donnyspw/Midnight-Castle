Skrip Python pembuat aset Midnight Castle (folder ini diabaikan Unity karena diakhiri "~").
- gen_art.py        : menggambar tile, objek, benda, efek, dan UI pixel art (PIL)
- make_sheets.py    : mengemas gambar menjadi sprite sheet + file .meta Unity (slicing otomatis)
- make_char_sheet.py: sprite sheet karakter contoh untuk scene ruang pamer
- proc_chars.py     : menyamakan ukuran & pivot frame karakter
- gen_audio.py      : sintesis musik latar & efek suara (NumPy/SciPy) -> .wav
- showcase_map.py   : peta ruang pamer
